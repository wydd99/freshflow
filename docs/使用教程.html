一、商家管理端 · 每天这样干（电脑使用）

管理端网址由配送站提供（建议收藏到浏览器书签）。登录后左侧为功能菜单，按一天的作业顺序讲。

1首页经营日报 —— 开工第一眼

  • 今日订单数、销售额、待分拣数、客户欠款总额四张卡 + 近 7 日销售趋势柱图。
  • 可切换日期回看；成本利润在采购价录入后自动计算。

2智能录单 —— 报单变订单（三种报法都能收）

  • 文本粘贴：把客户微信里发的文字单（"客户甲：奶白菜一斤，土豆两斤"）直接粘贴 → 识别 → 自动拆成商品行。
  • 拍照识别：上传手写单 / 打印单 / 微信聊天截图 → AI 逐行识别 → 自动列出商品行（表格单据空白行自动跳过）。
  • 识别结果三色区分：已匹配直接用；待选点下拉确认正确商品；未匹配点「一键建档」当场入库（填品名 / 分类 / 单位 / 价格）。
  • 单位栏：默认跟随单据原文（件 / 包 / 盒照抄），下拉可快速换成常用单位，也可手动输入自定义。
  • 核对无误 → 「保存为草单」→ 到订单页确认。
💡 识别口径：肉眼能看清的字基本都能识别，特别潦草的可能有误——所以保存前请扫一眼结果列表。越用越准：常用错别字建档时加进商品"别名"即可。

3订单池 —— 确认与锁单

  • 客户在商城下的单、后台代录的单，都汇总在「订单」页。
  • 状态流转：草单 → 已确认 →（分拣）→ 待发货 → 已发货。草单核对无误后点「确认」才进入履约；有问题可「作废」。
  • 新增订单（后台代录）：选客户 → 逐行选商品，单价自动按该客户的价格带出 → 保存草单。
  • 客户欠款超上限或超期未结时，新建 / 确认订单会被自动拦截，急单可点「强制放行」应急（系统留操作记录）。

4分拣屏 —— 装货作业台

  • 选日期（今天 / 明天）→ 左侧订单队列按颜色区分进度：蓝 = 未开始、黄 = 进行中、绿 = 完成。
  • 点订单 → 输入每个商品的实际分拣数量（支持小数，如 4.5 斤）→「完成分拣」→ 自动跳到下一个商品。
  • 缺货点「缺货」登记（黄色卡片保留在待处理区，可随时点击恢复继续分拣）；分错的在已分拣列表点击可改，覆盖前有二次确认；「累加称重」会把新称的量加到已累计值上。
  • 整单分拣完 → 点「确认发货」：订单转为已发货，货款自动记入客户欠款。

5打印中心 —— 三种票据

  • 配货单（A4 纯文字）：给配货员装货用，大字清晰。
  • 出库单（A4 表格）：含人民币大写金额、三联签字栏，随货给客户。
  • 小票（80mm）：热敏小票打印机用。
  • 选订单 → 选模板 → 预览 → 打印（浏览器打印框里选打印机；想先存档可选"另存为 PDF"）。打印次数自动记录，补打有据可查。
  • 金额口径：分拣过的订单按实际称重数量出单，未分拣的按下单数量。

6对账 —— 收款与对账单

  • 客户行点「登记收款」：填金额确认，欠款立即减少（欠款清零后客户自动恢复下单资格）。
  • 点「对账单」：选月份生成月度对账单（期初欠款 / 本月应收 / 本月收款 / 期末欠款 + 逐笔明细），可打印盖章或存 PDF 发给客户。

7设置 —— 修改自己的密码

  • 旧密码 + 新密码即可修改。密码要求：含大写字母、小写字母、数字中至少两类。

二、商家管理端 · 开张前设置（一次性）

1商品管理 —— 维护菜品档案

  • 点「新增商品」填写：品名、分类、单位（默认斤）、称重类型、基准价。别名很重要——填上手写单常见的叫法（如鸡蛋的别名"鸡旦"），智能录单识别准确率会大幅提高。
  • 批量导入：点「下载导入模板」→ 在 Excel 里按模板填好全部商品 → 点「批量导入 Excel」一次入库。
  • 「商城可见」开关：关掉的商品不会出现在客户订货页。
  • 「商品介绍」：填了之后客户在订货页点商品名可看到介绍和规格。

2客户管理 —— 维护订货客户

  • 新增客户时设置：等级（A/B/C 类，对应不同价格档）、结算方式（当日结 / 月结 / 货到付款）、欠款上限和超期禁单天数。
  • 「商城可见」：设为"指定分类"后，该客户只能看到勾选分类里的商品。
  • 客户登录用的子账号由管理员开通后发给客户（客户不支持自己注册）。

3报价 —— 一客一价

  • 批量改价（日常主力）：选客户等级 → 调价方式（按基准价上浮 X% 或统一价）→ 预览确认 → 执行，当天生效。行情变了每天早上花 10 秒调一次。
  • 按商品查价：给某个客户单独设"专属价"（最高优先级），或查看某商品的全部价格历史。
  • 客户下单时自动按「客户专属价 → 等级价 → 基准价」取价，无需手动改；客户只能看到自己那一档价格。

三、商家管理端 · 进阶模块

📋 以下模块按账号开通：看不到「采购」「库存」菜单属正常（未对你的账号开放），需要时联系系统管理员。

1采购计划 + 采购中心 —— 按需进货

  • 采购计划：选发货日期 → 系统把这段时间所有已确认订单按商品自动聚合出"需采购量" → 填预计到货日和供应商备注 → 一键生成采购单（PO 编号）。
  • 采购中心：按状态跟踪采购单（待到货 / 部分到货 / 已到货）；到货逐行回填实际到货量和采购价。
  • 到货自动入库进库存；采购价自动喂给首页的成本利润和录单页的"最近价"参考。

2库存台账 —— 水位与预警

  • 每个商品显示当前库存水位和预警阈值；降到阈值以下标红提醒。
  • 库存自动联动：采购到货 +入，订单发货 −出，不用手工记账。
  • 盘点差异走「手工调整」，调整记录留痕可查。

四、客户订货端（手机使用）

订货客户 两种方式任选，数据实时同步：

📱 方式一：微信小程序「鲜配订货」（扫体验二维码进入）
🌐 方式二：手机浏览器打开订货页（网址由配送站业务员提供，可添加到手机桌面）

1下单

  • 登录后按分类浏览商品，价格已按贵司等级自动显示，无需询价。
  • 点 ＋/－ 调数量，也可直接在数量框输入（支持半斤 0.5 等小数）。
  • 点商品名称可查看商品介绍和规格。
  • 底部「去下单」→ 核对清单 → 选发货日期 → 确认下单。

2🎤 按住说话报单

  • 商品列表底部有「按住说话下单」按钮：按住 → 直接说（"西红柿十斤，土豆五斤"）→ 松开。
  • 系统自动把你说的话变成订货清单，核对弹窗确认后即下单。
  • 说的商品里如有商城没有的，会提示略过；识别不准时可改用手工选货。

3再来一单

  • 「我的订单」里每张订单有「↻ 按此单再来一单」——点一下复制上次全部商品，按今日最新价格重算，确认即下单。日常补货十秒搞定。

4我的订单与对账

  • 「我的订单」可查看每笔订单状态（草单 / 已确认 / 分拣中 / 已发货 等）。
  • 「导出明细」可下载订单明细表；「月度对账单」可按月查看期初 / 应收 / 收款 / 期末并打印存档。
  • 只能看到自己公司的订单和价格，数据互相隔离。
⏰ 请在配送站规定的截止时间前下单；下单后如需修改，请联系业务员。
