# FreshFlow 运维手册 · 平台管理与代维护台

> 读者：平台运维人员（替商家开荒建档、售后代维护的同事）。
> 更新：2026-09-16，对应版本=代维护台 U6 上线版。界面有升级时以实际页面为准，本手册会同步更新。

---

## 一、这个界面是干什么的

「平台管理」是平台方的总后台，只有白名单账号能进。里面有四块：

| 功能 | 用途 | 谁会用 |
|---|---|---|
| 租户一览 | 看所有商家的经营概况、停用/启用商家 | 运维 |
| 账号总览 | 全平台账号清单（谁是商家、谁是顾客、属于哪家） | 运维排查问题 |
| 新建租户 | 给新签约商家一键开店铺（建号+初始数据） | 运维 |
| **代维护** | **替商家录商品/客户档案/价格**（本文重点） | 运维 |

**代维护的商业定位**：收费开通陪跑服务。新商家不会用电脑，运维替他把商品、客户、价格录进去（首年含 2 小时代录服务，超出按次计费）；日常售后商家打电话来"帮我把土豆改个价"，也走这里。

**三条铁律**（违反=事故）：

1. **永远不要索要商家的登录密码**。代维护是平台授权的专用通道，不需要商家密码；商家密码始终在商家手里。
2. **每一步操作都会自动留痕**（谁·何时·替哪家·改了什么），事后可审计。所以放心操作，但也别乱操作。留痕只在平台侧可见——商家自己的「操作日志」页不会显示平台代录记录。
3. **代维护没有删除功能（故意设计的）**。录错可以改；要删除请商家在自己后台操作，或联系平台管理员。

## 二、怎么登录进入

1. 浏览器打开后台地址：`https://freshflow-ENV_ID-0000000000.tcloudbaseapp.com/`
   - 首次访问会出现腾讯云的"风险提醒"页，等倒计时结束点**「确定访问」**即可（这是测试域名的固定提示，正常现象）。
2. 输入平台方账号登录：`administrator / TempPwd000`（当前演示期账号；正式运营时管理员会给你发运维专属账号）。
3. 左侧菜单点**「平台管理」**→ 页面顶部有四个标签：租户一览 / 账号总览 / **代维护**。
4. 进入「代维护」，第一件事：**在下拉框选择要维护的商家租户**。没选租户前页面是空的（提示"请先选择商家租户"），选完后商品/客户/价格三个子面板自动加载。

**常见登录问题**：

- 提示「当前账号不是平台方」→ 你用的不是白名单账号。找系统管理员把你的账号加进 `PLATFORM_UIDS` 名单。
- 提示「登录已失效，请重新登录」→ 会话过期了，退出重登即可。
- 同一账号在两台电脑登录，一台会被挤下线 → 属正常现象，重新登录即可。

## 三、代维护操作详解

### 3.1 商品面板（选租户后默认显示）

**表格列说明**：编码（系统自动生成，10位数字，不要手改）/ 品名 / 分类 / 别名 / 单位 / 基准价 / 商城可见 / 状态 / 操作。

#### 新增单个商品

点「新增商品」，逐字段填写：

| 字段 | 怎么填 | 说明 |
|---|---|---|
| 品名* | 必填 | 商品的正式名称 |
| 分类 | 下拉选，或**直接输入新分类名** | 输入的新名字会自动创建分类，不用先去建分类 |
| 单位 | 默认"斤" | 按份卖的填"份""箱""瓶"等 |
| 基准价 | 数字，默认 0 | 没有等级价/专属价时顾客就按这个价结算 |
| 别名 | 分号分隔，如 `鸡旦;土鸡蛋` | **很重要**：智能录单识别手写单、顾客搜索都靠它匹配。商家口头怎么叫就怎么写 |
| 规格 | 如 `30枚/箱` | 选填 |
| 商品介绍 | 文字 | 选填，商城商品详情展示 |
| 商城可见 | 默认开 | 开=顾客在商城能看到并下单；关=隐藏（内部用品如周转筐就关掉） |

保存后提示「已创建（编码 xxx)」并自动刷新列表。

#### 编辑商品

点行尾「编辑」→ 改字段 → 保存。**编码不会变**，放心改名字和价格。已停用的商品编辑后仍是停用状态（不会被误激活）。

#### 批量粘贴录入（开荒建档主力）

点「批量粘贴」，文本框里每行一条，格式：**`品名,分类,单位,基准价`**，例如：

```
白菜,叶菜类,斤,3.5
土豆,根茎类,斤,2.8
番茄,,斤,5
香菜,叶菜类,,
```

规则：

- **必须用英文逗号**（中文逗号，会导致该行失败——失败结果里会列出第几行什么原因，改好重新粘贴即可）。
- 顺序固定：品名在最前，基准价在最后；分类/单位/价格可以留空（留空=不设分类/默认斤/价格0）。
- 空行自动跳过。点「开始录入」后逐条写入，结束弹出结果：成功 N 条 / 失败明细（带行号和原因）。
- 同名商品不会自动去重——粘贴前先搜一下品名，避免录重。

### 3.2 客户面板

点「新增客户」，字段说明：

| 字段 | 怎么填 | 这个字段管什么 |
|---|---|---|
| 名称* | 必填 | 客户（餐馆/食堂）名称 |
| 等级 | 普通 / A / B / C | 决定客户享受哪档**等级价**；不设等级价就都按基准价 |
| 结算方式 | 当日结 / 月结 / 货到付款 | 月结需再填「每月结账日」（1-31，只有选月结时才出现这一栏） |
| 欠款上限 | 数字，留空=不限 | 客户欠款超过这个数，系统**自动禁止下单**（提示欠款超上限） |
| 超期禁单天数 | 默认 30 | 客户有超过 N 天没结的欠款时，**自动禁止下单** |
| 可见全部商品 | 默认开 | 开=商城能看到全部上架商品；**关=只看授权分类**。注意：分类授权清单只能在**商家自己后台**设置，代维护做不了这一步——如果需要按分类限权，录完提醒商家自己去设置 |
| 备注 | 文字 | 如"老板娘微信 xxx" |

### 3.3 价格面板

**先搞懂取价规则**（顾客实际成交价的优先级）：

> **客户专属价 > 等级价（A/B/C）> 基准价**，且只取「生效日 ≤ 今天」里最新的一条。同一个价格当天重复设置=覆盖当天的（历史保留可查）。

操作流程：

1. 顶部下拉选商品（支持按编码/品名搜索）。
2. 右侧表格显示该商品**当前生效价**：每行=一种价格（等级价/客户专属价）+ 当前价 + 生效日。点行首箭头可展开看**全部历史价格**（只读，改不了删不掉）。
3. 下方「新增/修改价格」：
   - **等级价**：勾选 A/B/C（可多选=一次给多个等级设同一个价）→ 输价格 → 保存。
   - **客户专属价**：切换后下拉选具体客户 → 输价格 → 保存（只对这一家生效）。
4. 保存成功提示「已生效（2026-09-16 起）」。**价格从今天起算，不影响历史订单**。

**注意**：

- 没有「批量改价」，也没有「删除某条价格」——都需要的话说明需求变了，反馈给平台管理员。
- 给顾客解释价格差异时：先问对方等级和有没有专属价，再看这个商品的当前生效价表。

## 四、平台管理其他功能（简述）

### 4.1 租户一览

所有商家的列表：套餐、启用状态、店家账户数、客户档案数、订单数。行尾可**停用/启用**商家（停用前有确认弹窗；停用后该商家整体无法登录使用——欠费/解约时用，慎点）。

### 4.2 账号总览

全平台所有账号：类型（商家/顾客）、登录名、角色（老板/店长/顾客）、所属租户、Uid。**排查问题神器**：商家说"顾客登录不了"，来这里查这个顾客的账号挂在哪家、状态是否正常。

### 4.3 新建租户（给新商家开店）

点「新建租户」向导，四步：

1. **商家名称**：如"示例商家B"。
2. **管理员账号**：字母开头，2-48 位（字母数字 . _ -），如 `merchant_b`。
3. **初始密码**：8-32 位，必须含大小写/数字中至少 3 类（如 `TempPwd000`）。**把这个密码当面交给商家**，商家后续自己改。
4. **安全模式**：开=顾客在新设备登录要短信验证（安全套餐卖点）；关=账号密码直接登录（方便但弱一点）。按商家签约套餐选。
5. 「商品分类种子」默认复制标准 7 分类（叶菜/根茎/调味等），商家什么都不用建就能开始录商品。

创建成功会提示账号信息，整个开店过程约 1 分钟。

## 五、常见问题处理（FAQ）

**Q1：保存时提示「品名必填」「价格必须大于 0」之类**
→ 按提示补字段。价格面板的价格必须大于 0（免费的东西不该出现在报价单里）。

**Q2：批量粘贴一半失败**
→ 看结果弹窗里的失败明细（第几行+原因）。最常见：用了中文逗号、价格列写了"3.5元"这种带单位的、整行只有一个词。修正后**只粘贴失败的那几行**即可，已成功的不会重复录入。

**Q3：录完商品，商家说商城里看不到**
→ 依次检查：① 商品「商城可见」是否为开（表格里"商城可见"列=否？）；② 商品「状态」列是否启用；③ 商家说的顾客是不是被限制了可见分类（见 3.2 可见全部商品）；④ 顾客端刷新页面。都没问题就到价格面板确认商品有没有价格（基准价 0 也会显示为 ¥0.00，但下单金额不对）。

**Q4：商家说顾客看到的价格不对**
→ 按取价优先级排查：① 这个顾客有没有设「客户专属价」；② 顾客所属等级有没有设「等级价」；③ 都没有就是基准价。价格面板里选中商品一眼就能看到当前所有生效价。

**Q5：录错了想删掉**
→ 代维护**没有删除功能**（防误删，故意设计）。处理：能改就编辑改正；确实要删，两个途径——让商家在自己后台删（商品/客户管理页都有删除按钮；商品删除前系统会提醒"有历史订单的商品建议停用而非删除"），或联系平台管理员处理数据库。

**Q5-附：商品想下架但又不想删**
→ 把「商城可见」关掉即可（代维护编辑弹窗或商家后台都能关）：顾客立刻看不到，历史订单和数据都保留。

**Q6：不小心把 A 商家的东西录到 B 商家了**
→ 到 B 商家租户下：商品改名备注清楚 + 提醒商家删除；价格不用动（不影响 A）。**预防**：操作前先看页面顶部的租户下拉框当前选的是谁，切租户后所有面板数据会整组刷新。

**Q7：改了价格，商家说老订单金额也变了**
→ 不可能。价格只对「生效日 ≥ 设置日」的订单生效，历史订单不会变。真遇到先核对对方看的是哪天的单。

**Q8：我改过什么自己忘了，商家对账有争议**
→ 每笔代维护都自动留痕（操作人·时间·替哪家·录了什么）。告诉平台管理员查 `op_log` 操作日志即可，不用自己记忆。

**Q9：页面卡住/点了没反应**
→ 先刷新页面（F5）。还不行就退出重新登录。代维护的每次保存都有成功/失败提示，**没看到提示=没保存成功**，别默认成功了。

**Q10：商家问"你们是不是有我们密码"**
→ 没有，也不需要。如实告知：平台有授权代录通道，所有操作有审计记录，商家可以随时改自己的密码（后台-设置）。

**Q11：商家会看到我们替他录了什么、改了什么吗？**
→ 不会。平台代录记录只在平台侧留痕（谁、何时、替哪家、录了什么），商家自己的「操作日志」页不显示这些记录。对账有争议时，由平台查内部日志回应。

## 六、代维护界面"不能做"的事（边界清单，避免白费劲）

| 想做的事 | 为什么做不了 | 正确做法 |
|---|---|---|
| 删除商品/客户/价格 | 无删除功能（防误删） | 商家后台删，或找平台管理员 |
| 停用/启用某商品 | 代维护和商家后台目前都没有启停开关 | 想下架=关「商城可见」；彻底删除见上条 |
| 给顾客设置"部分分类可见"的分类清单 | 代维护只有总开关 | 商家后台「客户管理」设置分类授权 |
| 批量改价 | 未开发 | 逐个商品设，或反馈需求 |
| 代商家下订单 | 设计上不做（商家有智能录单） | 教商家用智能录单 |
| 开/停商家子账号、改顾客密码 | 商家自助功能 | 商家后台「客户管理→子账号」 |
| 查操作日志 | 日志在数据库 | 找平台管理员查 op_log |
