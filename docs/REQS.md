# FreshFlow · 需求验收清单（源自演示对话的 19 条真实需求）

> 来源：《鲜橙供应链_深入分析v2_含语音情报.md》第一节。**本清单=本项目的需求边界**：清单内功能做完算完成；清单外功能一律进 P3 备选池，不承诺。
> 【用户】请逐条过目，有异议直接在编号后批注。

| # | 需求 | 验收方式 | 交付期 |
|---|---|---|---|
| 1 | 商家通过小程序自助下单 | 小程序下单→后台订单池可见 | P1 |
| 2 | 五种录单输入：语音/手写拍照/打印单拍照/Excel/文本粘贴 | 每种各演示一单成单 | P1 |
| 3 | 草稿单→现场称重改重改价→出货单 | 一单从草单走到出货单数量已变 | P1草单+P2改重 |
| 4 | A4 纯文字竖排配货单（无表格只要品名数量） | 打印预览视觉验收 | P1 |
| 5 | 分拣状态：蓝未开始/黄干一半/绿干完，干完一家清空一家 | 分拣屏演示 | P2 |
| 6 | 一客一价/一客一品 + 按客户类型批量改价 + 按客户过滤可见商品 | 同商品两客户不同价；不可见商品搜不到 | P1 |
| 7 | 结算规则：当日/月结/货到付款；欠款上限锁单；超期未结禁下单 | 规则触发演示（超上限下单被拦） | P2 |
| 8 | 验收改重：手机改数字，对账按最新数据；留痕 | 改动前后对账单数值变化+留痕记录 | P2 |
| 9 | 客户子账号：只看自己单；后台可导出、前台不给导出 | 子账号登录演示+导出权限开关 | P1(P2导出) |
| 10 | 商城可自定义：可下单时段、起订量校验 | 时段外下单被拦；低于起订量被拦 | P1 |
| 11 | 白牌：商城名/登录名可自定义 | 换名演示（schema 已原生多租户，商家A版即可换名；完整多租户见 P3） | P3（已定版为正式目标） |
| 12 | 手写识别预期：可辨认字基本能识；失败=未建档一键维护 | 3-5张真实单据实测报告 | P1 |
| 13 | 操作者画像：大按钮、有图有字、免培训 | 分拣屏视觉+一次实操 | P2 |
| 14 | 打印：小票/A4/多模板；补打计数 | 三件套+打印记录演示 | P1 |
| 15 | 耗材：标签贴纸支持（标品打N张） | 五瓶酱油打5张贴纸演示 | P2 |
| 16 | 客户/商品/价格表格批量导入导出 | Excel 导入建库演示 | P1 |
| 17 | 语音开单→秤屏同步显示 | 开单后分拣屏出现该单 | P2 |
| 18 | 称重实重自动回写订单与出货单 | 1斤下单/4.12斤实称→出货单显示4.12 | P2 |
| 19 | 日报表：今日成本利润、销售汇总（老板手机可看） | 小程序报表页截图 | P2 |
| 20 | **采购计划**：按订单自动汇总待采购商品清单（9/10 用户追加） | 今日订单 → 采购清单聚合演示 | P2 |
| 21 | **采购中心**：采购单管理（手工建/从计划生成/到货标记/采购价记录）（9/10 用户追加） | 建采购单→标记到货 全流程 | P2 |

**明确不做**（鲜橙有但未纳入需求）：采购对账、供应商入驻、营销优惠券、溯源大屏、菜篮子工程、大米称重、加工/入库子系统、CRM、完整进销存。（采购计划/采购中心已按用户 9/10 指示纳入 P2；若后续要"按供应商自动拆采购单"，需先补"供应商档案"设计，届时再议。）
