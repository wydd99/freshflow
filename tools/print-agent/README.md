# FreshFlow 云打印薄代理（T2.9）

本机常驻小工具：轮询「已分拣待发货」的订单，自动生成配货单并调起系统打印。
配合分拣流程实现「无人值守自动出单」——分拣员在分拣台上点完成后，配货单自动从打印机出来。
后台「打印中心」的手动打印不受影响，随时可补打。

## 使用步骤

1. 装 [Node.js 18+](https://nodejs.org)（装完 `node -v` 能出数字即可）
2. 把本文件夹放到任意位置（建议随系统盘一个固定目录，如 `D:\FreshFlowPrintAgent`）
3. 复制 `config.example.json` 为 `config.json`，填写：
   - `username` / `password`：后台管理员账号（建议单独为打印代理用一个管理账号）
   - `printCommand`：可留空（用系统默认打印机）；如果打印效果不理想，按打印机类型配置
4. 双击运行 `node print-agent.js`（或建一个 `启动打印代理.bat`，内容 `node "%~dp0print-agent.js"`，放桌面）
5. 窗口保持开着即可。**首次运行只记录现状、不会打印历史订单**；之后每当有新订单变成「已分拣待发货」，自动打印一张配货单

## 两种打印模式

| 模式 | 配置 | 适用 |
|---|---|---|
| 系统默认打印 | `printCommand` 留空 | 普通家用/办公打印机（调浏览器打印，可能弹一次窗口确认） |
| 自定义命令 | 如 `"C:\\Program Files\\SumatraPDF\\SumatraPDF.exe" -print-to-default "{file}"` | 追求静默、稳定的现场（推荐装一下 SumatraPDF 用它打印） |

## 常见问题

- **重复打印？** 不会——代理记住已打印的单号（`.print-agent-state.json`），每单只自动打一次；要补打去后台打印中心手动打。
- **想停掉自动打印？** 关掉窗口（或 Ctrl+C）。
- **打印位置/纸张不对？** 那是打印机驱动的设置问题（系统里设置默认纸张和边距），与代理无关。
- **安全**：代理用管理员账号登录（不是长效密钥），登录凭证只存在这台电脑的 `config.json`，别把该文件外发。
